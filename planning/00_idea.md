Aplikasi backend RAG pipeline buat ngolah kursus online (video/audio) jadi knowledge base yang bisa di-query. Admin upload video/audio, sistem transkrip otomatis, dipecah jadi chunks, di-embed, terus klien bisa nanya soal materi videonya dan dapat jawaban akurat plus referensi segmennya. Rencana mulai dari demo ke klien B2B dulu, kalau deal baru scale ke production.gw mau ada 2 table yaitu table utama untuk retrieval dan tabel 2 untuk sumary satu vidio.alur nya adalah saat admin upload vidio maka akan mengirim vidio itu ke whisper large di groq api lalu transkrip nya akan di ambil oleh dua proses berbeda yaitu chungking - embeding - inject ke table retrieval.lalu proses sumary yang mana ambil dari transkrip - kirim ke deepseek api untuk generate sumary - simpen ke table sumary.gw mau di tiap chunk ada metadata sebagai sitasi dan juga gw mau ada fitur biar bisa filter query berdasarkan segmen,semisal saat admin upload vidio berjudul html dasar dengan segmen web desain maka saat query client bisa kirim ingin query ke segmen web desain agar retrieval lebih terpusat,gw juga mau ada fitur mengolah pdf dengan llamaparse api,untuk embeding gw mau pake bgem3 dari cloudflare ai worker,untuk database gw mau pg dengan pgvektor,untuk chungking gw mau parent child chunk dengan 1 kalimat pertama untuk child dan parent dengan 3 kalimat setelahnya.untuk tech stack gunakan golang nethttp dan untuk database menggunakan supabase/neon lalu untuk repo layer gunakan sqlc.untuk penyimpanan file sementara taruh di r2
